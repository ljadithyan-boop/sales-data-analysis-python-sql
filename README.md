# 📊 Power BI Dashboard — BehindTheCart

## Overview
Interactive sales analytics dashboard built on 10,000+ rows of retail data using Power BI Desktop.

## File
`BehindTheCart_Dashboard.pbix` — open with [Power BI Desktop](https://powerbi.microsoft.com/desktop)

## What's Inside
- 📈 Monthly & yearly revenue trends
- 🛍️ Category and sub-category sales breakdown
- 🌍 Region-wise performance analysis
- 💰 Profit margin tracking
- 🔍 Interactive slicers for date, category, and region

## Data Source
Cleaned retail dataset (`superstore_cleaned.csv`) processed via Python (Pandas) and stored in SQLite.
